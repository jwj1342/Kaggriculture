**三条结构性结论**:
1. **食谱决定一切**:三个磁带臂全部 7/12 且全部胜 main;四个 barnyard 食谱的
   奖励修复臂 5–6/12、无一胜 main——尽管它们对 barnyard 的 margin 最大
   (byre +40.5k)。**把 barnyard 打爆是对 barnyard 过拟合。**
2. **"真"不等于"有用"**:两个最有原则的奖励项都被磁带压力否掉——执行价
   计价(bourse)与 base 价资本信用(harvest,50 迭代内收入从 39.6k 跌到
   32.6k,已杀)。凡依赖"能按 base 卖出"的项,只在弱对手食谱里成立。
3. **一天的位移**:四墙 margin 从 −103k(昨晨 cropper)到 **−67k**,灾难局
   从 20% 到 **2%**,收入中位 35.7k → 53.0k。**但四墙仍然 0 胜**——这是
   1364 档与 2000 分之间那道坎的位置。
