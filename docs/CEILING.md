# 天花板测量：价值到底住在哪里（2026-09-05）

`docs/RUNS.md` 是一万六千行的流水判词，本文件把 09-04/09-05 两天做完的**天花板测量**
提取成一份可交接的东西：**用了什么台架、每道门怎么定、每个维度量到多少、还剩什么没关**。

**一句话结论**：在我们能测的每一个维度上，「`n04` 的农场带子 + `closer_cleo` 的卖出层」
离天花板都只有**约 1,000 的 margin**；而它在天梯上是 **1,988.7**，距银线 **2,282.8**
还差 **294 分**。**那 294 分不在卖出层、不在把生产条件化于商店抽签、也不在换另一条挖来的带子里。**

## 一、台架（每一件都有自己的门）

| 工具 | 做什么 | 它的门 |
|---|---|---|
| `tools/sellsim.py` | 卖出侧前向模型：回合内逐单位价格行走、小镇消耗、对手卖出反推 | **逐美元复现引擎的每一个市场回合**；948 回合、45 个**同槽位争夺**回合、0 不一致 |
| `tools/oppmodel.py` | 用**可见状态**预测对手下一/未来 3 回合卖什么 | 报 precision/recall/F1 对 base rate；`always-no` 作平凡基线 |
| `tools/window_cem.py` | 回退课程 + 订单空间残差 + CEM | **零 knobs 必须逐位复现 cleo**；no-op 率按「成交为 0 的订单数」算并与 δ=0 比 |
| `tools/variance.py` | 把 margin 的方差拆到棋盘 / 商店抽取 / 对手 | 三个因子独立操纵：**保持解锁时刻与数量、只换是哪几家**，杂草 RNG 不受影响 |
| `tools/branch_bound.py` | 条件化生产的先知上界（把挖来的带子当分支） | 预登记判据：任一 ≥ +10,000 ⇒ 建树；两者 < +5,000 ⇒ 生产侧也近天花板 |
| `tools/nashrank.py` | Nash 平均 / α-Rank / IQM（圆桌 AvA、面板 AvT 两种形式） | 与七次「顶端排反」同一套预登记门 |
| `tools/answer_key.py` | 从第三方天梯对局造顶端答案钥匙 | — |
| `tools/liquidate.py` | 引擎级卖出经济学 + 逐单位成交 trace + 上界 | 席位归属必须 100%，否则拒绝写文件 |

### 引擎里三条决定一切的机制（都从 `reference/engine/kaggriculture.py` 读出并验过）

1. **回合内是逐单位锁步，而且双方按同一 pre-commit 库存报价**
   （`_process_market` 的 `quoted` 循环在任何 `_commit_unit` 之前填满）。
   **⇒ 同一回合内没有先手价格优势；抢跑只能跨回合生效。**
2. **"争夺"是同槽位，不是同回合**（外层循环是槽位 `i`）。
   **⇒ 把卖单放在对手买/卖所在槽位之外，两边就不互相走价。**
   （这条同时是重放的陷阱：重排订单列表就换了结算。）
3. **没卖掉的货在终局值 0**（分数 = 终局的钱）。
   **⇒「别往塌掉的市场里砸」永远不是最优，以 $1 卖掉也严格优于持有。**

## 二、统计纪律（09-05 起强制）

- **门只报一种统计量：配对差额的中位数 + seed 簇 bootstrap 的 95% CI。**
  不再并列未配对中位 ——「中位数之差 ≠ 差之中位数」在一天里出现**三次**，
  而且**符号相反**（⑮ 的门 1、`longcredit` 追溯、上界读数各一次）。
- **每条臂开跑前按要检测的效应量算 n**：看 **+20k 用 40 局够**；**看 +3k 要 400 局以上**。
  依据：同一批 40 局给出未配对 −3,899 / 配对 +4,672、CI 宽 ±8k。
- **每个胜负类读数带已知阳性**；已知阳性不成立时读数作废，不是"差不多"。
- **人工固定环境（如强制商店组合）之后，该环境里的最优解不能外推回自然环境。**

## 四、关闭的家族与依据

| 家族 | 依据 |
|---|---|
| **一回合一个宏的市场头，及其上的任何 reward / λ / 回报重分配** | **机制**：在 cleo/k01 访问的状态上，`mkt-w4` 给它们那一单的几何均概率是 **4e-7 / 3e-10**；且它们 **40% / 64%** 的卖出回合出 ≥2 单，**头在任何概率下都表示不了** |
| 冻结农场 + PPO 学 SELL（⑬）与其相对形变体（⑮） | 门 1 −87,246 / −42,291 / −25,624，0/40 与 0/20 配对局 |
| 重排卖出时机（切片 / 时移 / 规避 / 抢跑） | 上表，含先知 |
| 卖出侧配置（比例 / 跳过） | +0，机制是"未卖的货值 0" |
| 条件化生产（带子树） | 先知上界 +962 < 预登记的 +5,000 |
| Nash averaging / α-Rank 作为顶端尺子 | ρ +0.912 对普通胜率 +0.929；圆桌上退化成点质量 |

**标为「待复核」而不是关闭的**：
- **模仿 / `--kickstart`** —— 教师 40%/64% 的回合出多单而头只能出一个宏，
  **交叉熵目标从一开始就是被截断的**，所以"与教师质量无关地有害"可能一直是表示缺口的表现。
  **头能表示多单之前不重排也不翻案。**
- **`longcredit`（λ=0.99）** —— 原判负 −3,703 用的是我方九对手中位钱；
  同一批 40 局配对复核是 **+4,672（CI 含 0）**，**降级为「未定」**。
  （回报重分配家族仍关闭，但依据换成 P≈1e-7 的机制。）

## 五、尺子的真实状态（这条改变了很多历史判词的读法）

- **「顶端本地尺子失效、复现 7 次」不成立** —— 它的已知答案 `k01 > k06` 本身无效：
  引擎内 **192 局 97–95**；两条提交败率 **0.220 / 0.213**（提交纪律要 1/3）；
  天梯上**分低的那条挣得多 5,288**；同一文件三次读到 1363.7/1218.6/1209.4（散布 **154 分**）
  而这一对只差 266 分。
- **顶端的分数排序对单局胜负有预测力，但很弱**：794 局第三方天梯对局，双方都 ≥1500 时
  600+ 分差只给 **60.4%**（强排序会给 90%）；`0–145` 档稳定 **46.5%**，在噪声内。
- **座位效应不存在**：896 局座位 0 胜率 **50.7% ± 3.3**（z=+0.40）。
- **按败率 ≥1/3 筛，我们从来没有过一个已定型的、高于 1,363.7 的天梯读数。**

**同一构造的三发落在 1,988.7 / 2,035.9 / 2,302.2（后者未定型）** —— 这一类看起来
**在 2,000 附近定型**，也就是铜档。到银线要 **+294**。

**这条链没有否掉的，只剩两个**：

1. **一个比全部 14 条挖来的带子都更好的农场程序** —— 不是在 meta 里重选，是**超过 meta**。
   注意 `bc83d986f121` 那 30 支队的中位分是 **2,625.8**，比我们高 600 多，
   而卖出层已被测到接近天花板 —— **差距要么在他们的 agent 是自适应的（我们是开环回放），
   要么在 `plan_ladder` 的归因本身**（它自己的三条局限）。
2. 接受 2,000 档是这套 meta 的平台期。

**RL 在这个框架里的位置**：揭示点上的分支选择是几十个状态的 MDP，**bandit/表格就够，
PPO 没有用武之地**；而现在连这棵树都被上界判定为不值得建。
RL 仍然**未定**（不是崩溃）的三种形态是：**自回归多单头**（头能表示教师后 BC 第一次可行）、
**cleo 基底 + 订单空间残差**、**RL 只学价值给搜索做叶子** —— 三者都从未被测试。
