## 执行前纠正

独立审查提出的主要问题：

1. k01 的 2302.2 是旧提交的历史读数，不能换算为今天重新提交后的第 317 名。
   本地最后一局记录为 08-16；k06 为 08-21，n04 为 09-08。
2. 累计败率达到三分之一不是收敛证明。最近 18 局分别为 k01 8胜10负、
   k06 2胜16负、n04 5胜13负，也不能单靠这18局推断当前强度。
3. 区间跨过零表示证据不足，不能判定非劣效。
4. 金币差的配对中位数用于解释机制。最终胜负只看谁的钱更多，所以选优同时
   看配对胜负变化（平局记半胜）。不把金币差换算为天梯分。
5. 原方案命令中的 `eval.py` 实际报告均值，和指定的中位数口径不同。
   本轮单独保存原始逐局结果，按对手报告中位数及 seed 簇 bootstrap。
6. 两份旧多文件包都有 `from plan import BLOB`。同一进程加载会有模块缓存污染风险。
   已确认 k01/k06 自包含文件分别与原包解码计划相同，除计划内嵌方式外 AST 相同；
   原 tar 内各文件与旁边源码逐字节相同。评测用冻结的自包含副本。
