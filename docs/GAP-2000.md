# 为什么还到不了 2000 分 —— 逐层拆解(2026-08-21)

数据来源:sower-it228(已提交)的 12 对手花名册、对 cleo 的三局实测、
w49/k06 磁带解剖、`tools/ladder.py stats` 的 737 局真实天梯统计。
每一条都是测出来的,不是推断。

## 0. 分数的标尺:2000 分在哪一档

我们自己的历史提交给了标尺(`kaggle competitions submissions`):

| 分数 | 是什么 |
|---|---|
| 506.9 | 本项目上一代 RL(v2):本地对 barnyard **0/96** |
| 699–736 | 早期手写线 |
| 1287.2 | closer_cleo 原版(第三方参考 agent) |
| 1363.7 | cleo + 终局控制器(我们改一行) |
| **2035.9 / 2302.2 / 2359.5** | **复现别人天梯计划的开环磁带**(不是我们的策略,不是 RL) |
| 2391.6 / 2612.3 | k01 / k06(天梯顶端队伍) |
| 3236.5 | 当时第一名 |

**2000 分不是"比 cleo 强一点",而是"打得过 1364 档并能和 2400 档掰"。**
本地花名册上我们对 1364 档(cleo/lena/bea)的胜率是 **0%**——差一整档。
好消息:2000 这条线在本竞赛是可达的(磁带复现做到过 2035.9),
坏消息:那次是复现顶端计划,不是学出来的策略;**用 RL 走到 2000 需要
真的把收入做到那一档**。

## 1. 决定胜负的量是收入,差距是 4 倍(不是 1.5 倍)

自博弈批次里我们收入 57k,看起来离 cleo 的 100k 不远。**但对真正的强手
实测是另一回事**(三局,采样导出,参考引擎):

| 种子 | 我们 | closer_cleo |
|---|---|---|
| 1000 | 21,867 | 107,670 |
| 2000 | 37,434 | 113,106 |
| 3000 | 28,360 | 109,241 |

**对 1364 档实测收入 22–37k,对手稳定 107–113k ——差 3–4 倍。**
57k 是打 barnyard(857 档)时的数字:强手会抢走镇上的需求、砸低价格,
我们的收入在压力下腰斩。这解释了为什么 margin 是 −82k 而不是 −45k。

## 2. 收入差的机械分解(三局终局形态实测)

| 指标 | sower-it228 | 天梯场地中位 | w49 / k06 |
|---|---|---|---|
| 解锁地块 | **2**(50 格永远 LOCKED) | 3 | 3–4 |
| 终局动物 | **5–7** | 13 | ~14 |
| 终局作物 | 2–6 | 3 | 季内 ~60 |
| 空闲地块 | 33–39 | 45 | — |
| 买地订单 | **1/局** | — | 3/局 |

三个硬缺口,按贡献排序:

**(a) 土地门(最大)**:只买 1 块地,**半个棋盘(50 格)整局锁着**。
可耕面积不足 → 作物 42 株(顶端 ~177 颗种子)、动物栏位不足。
势函数把一块地标价 300,而它实际解锁 ~5k 的下游作物信用——
梯度隔着两步链。修法已上膛:`--land-value`(plowman A/B 在跑)。

**(b) 存栏门**:动物 5–7 只 vs 场地 13、k06 14。牛奶 19.3% 的收入线
只有场地一半的产能,化肥原料(动物粪)同步减半——k06 的化肥占其收入
31.8%,我们 16.1%。

**(c) 小麦对冲成了纯亏损(新发现,最容易修)**:

    收入端:WHEAT 卖出 141,999(占我们总收入 48.6%,3,197 单位)
    支出端:WHEAT 买入 163,175
    净额:  −21,176

**我们买进 16.3 万的小麦、卖出 14.2 万,净亏 2.1 万,而这相当于我们
一局收入的三到四成。** 这不是喂食需求(存栏只有 5–7 只,一天吃不到
20 单位):策略在跟自己做市——买入推高价、卖出压低价,每个来回付掉
价差。势函数里棚内小麦按 min(市价, base)×0.9 计价,所以这个来回在
"势"上近乎中性,唯一的成本是市场冲击,而市场冲击没有进势函数。
这是一个典型的**未被奖励惩罚的无效循环**(不是 reward hacking——
它没有骗到分,只是没人罚它)。

## 3. 训练层面的四个限制(为什么曲线会在某处停)

1. **对手档位天花板**:主训练对手是 barnyard(857 档)。对 857 档的
   最优反应不等于对 1364 档的可行策略——我们把 barnyard 打到 92.7%
   之后,梯度里就没有"更强对手"的信息了。磁带(w49/k06)是**开环
   录音**:不反应、可被利用,只提供市场压力和产量参照,不提供对抗。
   **场上没有一个 1364 档的反应式对手可训**,这是结构性缺口
   (cleo/lena 是 python 脚本,张量引擎无法当对手用)。
2. **教师档位**:kickstart 老师是 barnyard 的意图。对 100k 经济而言
   它是错的老师(harrow 因此把 ks 关掉)。
3. **势函数的三处近似**:土地 300(在修)、动物产出按 base 计价
   (hinge 平衡下蛋价冲到 3× 而鹅无人养)、**没有市场冲击项**
   (于是第 2 节 (c) 的自砸价格不被惩罚)。
4. **采样温度的代价**:部署必须采样(argmax 模式在此族系统性崩坏),
   温度 1.0 下策略熵 13–14 nats,意味着每回合都在多个近似动作间抖动。
   打弱手无妨,打强手每次抖动都是漏点。

## 4. 测量层面的两个不确定性

- **本地场地不是天梯**:除 `agents/spar/`(从真实录音重建)外,场地
  是我们自己写的;历史上出现过"本地 384/384 全胜、天梯持平"的案例。
- **规则 7**:新提交前几小时的分数是地板不是水平,要等它输掉 1/3 的
  对局才算数。刚提交的 sower-it228 现在的读数不可用于任何决策。

## 5. 到 2000 需要什么(按预期收益排序,全部可 A/B)

| 杠杆 | 预期收入变化 | 状态 |
|---|---|---|
| 土地按解锁价值计价(→3–4 块地) | +20~30k | **plowman A/B 在跑** |
| 掐掉小麦对冲循环(买入上限 = 存栏需求) | +15~20k(直接止损) | 待做,改动小 |
| 存栏推到 13–14(build 曲线动物项加权) | +15~20k | 待做 |
| 化肥产业化(施用 30→120,销量 →3000 级) | +15~20k | 词表已有,曲线待调 |
| 卖出定价/节奏感知 hinge(避免自砸) | +10% | 待设计 |
| 纯顶端经济饮食 | ? | **harrow A/B 在跑** |
| 长链 800–2000 迭代 + PBT | 斜率延续 | 判词齐后自动开 |

粗算:前四项若各拿到一半,收入 57k → 100k 量级,可与 1364 档掰腕子,
天梯落点约 **1300–1600**。**再往 2000 需要第 4 节的结构性突破**:
一个 1364+ 档的**反应式**对手(把 cleo/lena 张量化,或用半反应式磁带
+ 扰动),否则我们只能学到"打得过 857 档、扛得住开环 100k 磁带",
而不是"赢得过 1364 档的应变"。

时间上不是问题:竞赛开到 2026-09-30,还有约 40 天;一条 800 迭代长链
约 8–9 小时,五臂并行每天能跑完三到四轮 A/B。**瓶颈是杠杆的正确性,
不是算力**——今晚的四个发现(日工、词表、原子物理、小麦对冲)都是
测量出来的,而不是猜出来的,这条路继续这样走。

# 追加(2026-08-21 午后):天梯首批读数 + 三个新证据

## A. 首个 RL 天梯读数:498.4(7 局 3 胜 4 负)

| 结果 | 我方收入 | 对手收入 |
|---|---|---|
| 胜 | 79.6k / 70.2k / 49.1k | 27.5k / 65.3k / 32.1k |
| 负 | 36.1k / 21.2k / 17.3k / 14.3k | 48.8k / 40.5k / 27.1k / 35.3k |

**这一档的对手只挣 27–65k**(不是 100k),我们输的四局是**自己只挣
14–36k**。所以在当前分段,瓶颈不是天花板,是**地板**。
(上一代 RL v2 收敛于 506.9;这个读数还在 7 局的地板期,规则 7。)

## B. 我们提交的是分布最差的那个检查点(教训)

三个候选的收入分布(各 1,152–1,248 局花名册,取我方收入):

| 产物 | <20k 的局 | 中位 | p95 |
|---|---|---|---|
| **sower-it228(已提交)** | **20%** | 35.7k | 70.2k |
| sower-tail(it 286) | 10% | 43.4k | 73.3k |
| reeve-tail | **8%** | **47.1k** | 74.7k |

it228 是链**中**检查点,先做完花名册就被提交了;链尾与 reeve 的地板都
明显更好。**教训:选交付物要看收入分布的下尾,不只看胜率。** 下一次
提交应从 reeve-tail / sheaf / granary 里挑 <20k 比例最低者。

## C. 采样温度:阴性结果(降温使地板更糟)

reeve-tail 在 T=1.0 / 0.7 / 0.5 三档(各 384 局):

| T | <20k | 中位 | grazier | main |
|---|---|---|---|---|
| 1.0 | 12% | 38.8k | **61.5%** | 8.3% |
| 0.7 | 18% | 37.6k | 17.7% | **17.7%** |
| 0.5 | **27%** | 32.8k | 0% | 8.3% |

**这一族的随机性是策略的一部分,不是噪声**:降温同时恶化地板与对手胜率
(argmax 崩坏是同一条曲线的极端)。T=1.0 保持为交付温度;T=0.7 对 main
略好,记为将来"对手相关温度"的线索。

## D. 地板是对手造成的,不是种子造成的

sower-tail 的 1,152 局按对手分组的**我方**中位收入:

    closer_cleo 25.2k | grazier 26.9k | lena 29.7k | bea 30.0k
    (全体中位 43.4k)

**强对手把我们的收入压掉四成**,而按种子分组只有 23.5k–62.0k 的自然
波动。同时商店组合影响明显:场上有 ICE_CREAM_SHOP 时我方中位 49.4k,
只有 PET_CAFE 时 40.0k(9.4k 的摆动)。

**结论修正**:此前把差距归为"产能不足"只对了一半。**同样的产能,在强
对手面前只能变现六成**——他们抢先吃掉镇上的需求、把我们主打品类的价格
砸下去。所以通往 2000 的路上,"卖得动"和"种得多"同等重要:

1. **势函数缺市场冲击项**(卖出按成交后价格计价)——当前势函数认为
   卖出不影响价格,于是策略学不到"分批卖 / 抢先卖 / 换品类卖";
2. **品类多元化**(顶端 5–6 条收入线,我们 3 条:小麦 48.6%、牛奶
   19.3%、化肥 16.1%)——单线被砸价时无处可去;
3. **小麦对冲止损**(granary A/B 在跑,实测 −21k/局);
4. **土地/存栏规模**(plowman A/B 在跑,收入已到 61.8k)。

前三项都指向同一个技术缺口:**奖励里没有价格影响**。这是下一代最该动的
一处,而且是 A/B 可测的:势函数把棚存按"若此刻全卖出的成交均价"计价,
而不是按 min(市价, base)。
