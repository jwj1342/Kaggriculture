## 4. 物理原因:浇水 / 施肥 / 收获是**乘性互补**

参考引擎 `_daily_refresh_plants`(第 787–803 行)与 `_decay_plants`:

- 持续作物在 `days_since_first % interval == 0` 时产出,**共 `max_yield` 次**;
- 每次加 **1 个单位**,**当天浇过水且在施肥期内加 2**;
- `yield_units` 上限 = `max_yield`,**不及时收,后续事件撞上限白费**;
- 过期后每 2 步扣 1 点,**存着的产量会烂掉**;
- **连续两天不浇水 → 整块地变杂草。**

**所以一株草莓值 4 个单位(裸)到 8 个单位(施肥且及时收)。** 非持续作物更极端:
小麦的 `yield_units` **只在产量窗口内浇水时累积**,不施肥上限 3、施肥 6。

**这三件事漏一环整个事件就折损,所以吞吐在乘积里有杠杆。** 同一段开局、同一批地、
只换网络:

| | 施肥 | 浇水 | 收获 | 单位/种子 | 收入 |
|---|---|---|---|---|---|
| 未训练的网 | 37 | 774 | 238 | 3.5 | 103,955 |
| endgame 训练过 | +22% | +18% | +19% | **5.0(+43%)** | 118,442 |
| cleo 自己 | ≈97 | — | — | 6.6 | 155,344 |

**三件事各多约 19% → 产出多 43%。** 这是反向课程最强的论据:它改善的是
每回合的照料吞吐,而吞吐正是这个乘积的杠杆。

## 7. 加东西之前要过的六条清单(2026-08-22 入档)

1. **零梯度 + 掩码链**:一个自己没有奖励、又只解锁一个被掩码动作的新动作,
   **加了等于没加**(stockman:帮手拿到 BUILD/PLACE,一整局用了 4 次和 0 次)。
2. **跨回合动作必须自己完成**:帮手任务**每回合重新采样**,新任务偏置在 −4.0
   时连续选中的概率约 2%(penner 未修版:取货 5 次、放置 0 次)。
3. **规则只在候选多于一个时有影响力**:先量"被调用且有选择"的回合数(种子那条
   是 **1**)。
4. **没跑过九对手数组就不算测过**:`IDLE_FERTILIZES` 在单一对手 4 个种子上
   **+6,548 且四个同向**,九对手是 **−438**。摆幅 7k。
5. **乘性互补**:浇水/施肥/收获缺一不可,**单动作补丁打不动乘积**。
6. **长链必须有留出集早停**:longhaul 629 迭代比 chisel 313 迭代**全面更差**
   (BEATEN 5/10 对 7/10、中位 43.4k 对 54.0k、grazier 7.3% 对 82.3%),
   而训练日志一直平在 50–52k、掩盖了退化。

**另一条老规律,2026-08-22 第七次撞上**:价格相关的机器**对不反应的对手有用、
对会反应的对手有害**(bourse / harvest / vise / ledger / seed / fert / …)。
