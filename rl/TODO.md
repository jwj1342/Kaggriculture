只有 Phase 1 产出有效 Option 后才搜索。第一用途是离线生成教师数据，不是在提交 agent
里实时跑 MCTS。

**状态：三动作 Phase 2 pilot 已证明 selector 受动作集合上限约束。先做阶段账本并产生
新复合 Option；随后在同一 Option 接口上实现离线搜索。仓库目前没有现成
beam/CEM/MCTS 骨架。**

- [ ] 在同一 Option 接口上比较 beam search、CEM/evolution 和 MCTS，以单位模拟步的
  validation return 选型，而不是预先指定算法名称。
- [ ] 搜索必须跨多个 seed、席位和对手；只优化一个确定赛季会重现旧 open-loop tape
  的泛化失败。
- [ ] 算力允许时精确 rollout 到 Option 终止或整局结束。Phase 0 的分时段校准通过前，
  不能拿当前 turn-level critic 当 MCTS 叶子；可以改用 Phase 1 反事实目标训练 macro
  critic。
- [ ] 保存 `(macro_state, legal_options, selected_option, return-to-go)`，再用事件平衡
  采样把搜索策略蒸馏进 Phase 2 controller。
- [ ] BUY_LAND 等稀有门控动作必须单独分层；普通逐步 BC 的频率权重已经在 `tutor2` 中
  把它们压掉过一次。
- [ ] **把参考轨迹从"初始化"升级为"全程锚"：在 RL 目标上常驻一个朝模仿先验的 KL 惩罚,
  并把策略条件化在从磁带抽出的逐日里程碑统计量上。**（2026-08-28 新增,机制缺口）

  **❌ 状态更正（2026-08-28 晚，判词 `ed4ad4f`）：这条的前半（常驻 KL/CE 锚）已经证否，
  不要再排。** `tutor-route` 用一个比我们的网好 **31k** 的教师
  （`barnyard:k01_route_s34_fert`），`ks` 数值健康 3.14、熵反而上升，策略仍在**一个
  迭代内**从 40,682 塌到 28,009；控制臂同期到 51,181。**所以有害性与教师质量无关，
  不是"等一个更好的教师"能解决的**——CE 项本身与 PPO 目标冲突。
  **仍然开着的只有后半**：把策略条件化在逐日里程碑统计量上（不含任何 CE/KL 项），
  它等价于 G1 战术计划的「第 0 步」，状态与保留意见见那一节。

  **范围更正（2026-08-28，`6a8c7ae` 之后）：这条不是"全缺"，是"半在建"。** 工作树里已经
  落地了 `--ks-class-alpha`（类平衡 kickstart CE，直接对着 `tutor2` 的失效模式：普通频率
  加权 BC 把 `BUY_LAND` 从 1.44% 压到 0.08%）与 `--kickstart-on-policy`（把教师项从
  纯初始化退火推向 on-policy）。**真正仍然缺的只有两件**：(i) 一个在 RL **全程**常驻、
  不退火的朝先验 KL；(ii) 把策略**条件化在逐日里程碑统计量**上。下面的机制说明按这两件读。

  现有做法主要在**起点**用参考轨迹（`--init-from` 的 BC 初始化、`--kickstart` 的退火 CE、
  Phase 4 的"低层以所选 Option 为条件"），退火结束后先验就
  不再约束策略,于是它可以漂回那条已知更差的行为分布。对照参考实现:AlphaStar 在 RL
  全程保留朝监督策略的 KL 惩罚,并把策略条件化在从人类录像抽出的统计量 `z`（编码建造
  顺序与产出单位）上,还对"跟上 `z`"发奖励;OpenAI Five 则直接把出装顺序**写成脚本**,
  只让 RL 打仗。两者的共同点是**宏观时间表始终来自数据或规则,从不是 RL 的搜索目标**。

  实现约束（已被本仓库测过,不要重犯）:**不能对整条磁带做朴素 BC。** cleo 的 712 回合
  里只有 **2 个** `BUY_LAND` 标签（1:115 对 SELL）,交叉熵会把它从 1.44% 压到 0.08%,
  `tutor2` 就是这样只拿到 +133。所以锚的对象必须是**逐日里程碑统计量**（day-1/day-12
  株数、帮手闲置率、每株收获次数）,而不是动作序列;稀有门控动作走上一条的单独分层。

进入 Phase 4 的门：搜索教师在未见 seed 和 held-out 对手上击败 Phase 2 controller，
蒸馏后的 controller 保留实质性收益。否则保留离线 planner，不增加联合训练复杂度。

## 降级候选

- **COMA 式因子化 baseline**：仍可能改善同一状态下 farmer 与 market 的归因，但它依赖
  对一个几乎不被采样的动作学出可靠 Q。先做模拟器反事实审计，再考虑 COMA。
- **Decision Transformer**：保留为离线序列备选，但现有 open-loop 数据有状态分布错位和
  稀有事件失衡。只有拿到 Phase 1 的事件平衡数据或搜索轨迹后再议。
- **推理期市场优化器**：策略足够强之后可作为部署 wrapper；单步卖出优化不是缺失的
  整季 planner。
- **继续扩模型容量**：保留 critic 分时段诊断，但不再排 width-only 实验。容量曾经是
  约束，后续延长已经不能移动战略平台。
